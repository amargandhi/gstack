# AI Usage Review

## One-Line Read
One sentence naming the strongest pattern in the reviewed window. Do not give an
overall grade.

## What You Were Trying To Do
State the apparent user intent from prompt evidence. If intent is unclear, say
that directly.

## What You Are Good At
Evidence-backed recognition. Each item must cite at least one evidence ID and one
source ID when it makes a recommendation.

## Patterns In How You Ask AI To Work
Recurring prompt/workflow patterns. Separate observation from interpretation.

## Where AI Was Underused
Feature-fit opportunities. Recommend features only when the evidence shape
supports them.

## Feature-Fit Coaching
Explain when each recommended feature fits and when it would be overkill.

## Second Opinion
Skipped, unavailable, budget-gated, or completed. If completed, include
agreement, disagreement, missed pattern, weakest recommendation, strongest
recommendation, and final adjustment.

## Teaching Notes
The clearest lessons from the run. Each note should include pattern, why it
matters, better move, evidence, and sources.

## Better Next-Time Prompts
Concrete rewrites the user can copy. Keep them specific to the observed prompt
shape.

## Next Session Script
A short trigger/behavior script for the next session.

## Source Links
All source IDs used in recommendations, with URLs.

## Evidence Coverage
Counts by source kind, user prompts, tool events, sessions, and warnings.

## Limits Of This Review
Coverage limits, schema skips, low-confidence areas, and anything the report did
not inspect.
